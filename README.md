# The Effective Speed of Algorithmic Repricing

Simulation code and minimal dataset accompanying the article:

> **A. E. Voipan, R. M. Dobrescu, N. Manea, O. Bucovetchi.**
> *The Effective Speed of Algorithmic Repricing: Computational Latency versus Strategic
> Interdependence in a Simulated Duopoly.*
> Journal of Theoretical and Applied Electronic Commerce Research (JTAER), 2026 (submitted).

This repository lets a reader **reproduce every number, table and figure** in the paper, either by
re-running the experiments or by reading the published result files in [`data/`](data/).

---

## What the study is about

Repricing bots can update marketplace prices at machine speed, but need not change prices at every
opportunity. The paper asks whether the **effective speed** of repricing (price changes per period)
is bounded by **computational latency** or by the **strategic interdependence** created when
competitors observe and react to each other's prices.

In a logit-demand duopoly with mean-reverting marginal costs, three decision rules are compared:

- a **myopic threshold** agent that reprices only when the one-period profit gain exceeds an
  adjustment threshold `C`;
- a **response-aware** heuristic that weights a candidate price against an assumed rival response
  (probability `ρ`), with no imposed threshold;
- a **tabular Q-learner** that discovers a pricing policy under a per-change switching cost.

The main control variables are the technical recomputation frequency `τ`, the rival-price
observation frequency `ω`, the adjustment threshold / switching cost `C`, the reaction probability
`ρ`, and the cost-shock volatility `σ`.

## Repository layout

```
src/repricing/        simulator package (demand, agents, beliefs, Q-learning, simulation loop)
experiments/          one script per experiment grid (+ extra/ for prices/profits & robustness)
tests/                31 unit tests (pytest)
data/                 minimal dataset: the result files behind the paper's tables and figures
requirements.txt      numpy, scipy, pandas, matplotlib, pytest
```

The simulator makes four concepts explicit and keeps them separate: technical opportunity (`τ`),
information (`ω`), ordinary adjustment friction (`C`), and strategic anticipation (`ρ`). A pricing
decision uses only the **last observed** rival price — the agent state contains no oracle for the
rival's true price, and a unit test checks this structurally.

## Requirements and installation

Python 3.10+.

```bash
python -m venv .venv && source .venv/bin/activate      # optional
pip install -r requirements.txt
```

## Running the tests

```bash
pytest -q
```

All **31 tests** should pass. They cover the demand system, the three agent types, the belief
rules, and the simulator (effective-speed metric, burn-in, simultaneous decisions, bounded
mean-reverting costs, and the absence of a hidden rival-price oracle).

## Reproducing the experiments

Each script writes its grid to `results/` (created on first run) and prints progress. Example:

```bash
python experiments/run_two_strategic.py          # baseline: technical capacity vs effective speed
python experiments/run_obs_tech_grid.py           # observability
python experiments/run_anticipatory.py            # response-aware agent
python experiments/run_cost_shock_robustness.py   # cost-shock volatility
python experiments/run_qlearning.py               # Q-learning (expensive: 500k training periods/seed)
python experiments/run_qlearning_gamma.py         # Q-learning gamma sensitivity
python experiments/extra/exp2.py                   # prices & profits (threshold agent)
python experiments/extra/exp2b.py                  # prices & profits (response-aware agent)
python experiments/extra/exp3.py                   # robustness to demand parameters
python experiments/extra/exp4.py                   # alternative (uncertainty-aware) belief rule
```

**Note on cost.** The full grids are computationally heavy (the baseline alone is 40 seeds × 12
technical frequencies × 4 thresholds × 5000 periods; the Q-learning runs train 8 agents for 500,000
periods each at every switching cost). For a quick smoke test, reduce `N_SEEDS`, `T`, and the
training length near the top of each script. The published numbers in [`data/`](data/) are produced
with the full settings listed in the paper (Tables 1–3).

## Dataset (minimal)

The files in [`data/`](data/) are exactly the aggregated results plotted and tabulated in the paper.
All speeds are **price changes per post-burn-in period** (burn-in 500 of 5000). Confidence
intervals in the paper are 95% intervals for the mean across seeds.

| File | Paper table(s) / figure | Generated by |
|------|------------------------|--------------|
| `data/baseline_speed_by_tau_C.csv` | Tables 4, A1; Fig. 2 | `run_two_strategic.py` |
| `data/observability_speed_by_tau_omega_C.csv` | Table 5; Fig. 3 | `run_obs_tech_grid.py` |
| `data/response_aware_speed_by_tau_rho.csv` | Tables 7, A2; Fig. 4 | `run_anticipatory.py` |
| `data/volatility_speed_by_sigma_C.csv` | Tables 8, 9 | `run_cost_shock_robustness.py` |
| `data/qlearning_speed_by_cost.csv` | Table 13 | `run_qlearning.py` |
| `data/qlearning_speed_by_seed.csv` | Table 13; Fig. 5 | `run_qlearning.py` |
| `data/extra/prices_profits_threshold.csv` | Table 10 | `experiments/extra/exp2.py` |
| `data/extra/prices_profits_response_aware.csv` | Table 11 | `experiments/extra/exp2b.py` |
| `data/extra/demand_robustness.csv` | Tables 12, A3 | `experiments/extra/exp3.py` |
| `data/extra/belief_rule.csv` | Table 6 | `experiments/extra/exp4.py` |

**Column glossary.** `tech_freq` = `τ`; `obs_freq` = `ω`; `cost_threshold`/`C` = adjustment
threshold or switching cost; `reaction_probability`/`rho` = `ρ`; `sigma` = `σ`; `reprice_rate_mean`
= effective speed (price changes per period, mean over seeds); `conditional_repricing_rate_mean` =
reprices per realised recomputation opportunity; `speed0`/`price0`/`profit0` = the tested firm's
realised speed, mean price and mean per-period profit (`*1` = the myopic rival); `init` = initial
price; `dem` = demand specification; `belief_sd`/`s` = uncertainty-aware belief standard deviation
per √period.
